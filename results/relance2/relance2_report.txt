5. ANALYSIS: Do silhouette and NC2 predict linear probe F1?
--------------------------------------------------------------------------------

ANSWER: Silhouette YES, NC2 PARTIALLY. The KNN results DO NOT fully transfer.

  Scheme A (11cls):
  - silhouette_score: ρ = +0.825 (p = 0.0010). Strong, significant predictor.
    This is the ONLY metric with ρ > 0.7 and p < 0.01 for linear probe F1.
  - nc2_deviation_etf: ρ = -0.497 (p = 0.1006). Moderate, NOT significant.
    With KNN, NC2 was ρ = -0.916 (p < 0.0001) — a DROP of 0.42 in ρ.
  - davies_bouldin_index: ρ = -0.350 (p = 0.265). Weak, flagged OUTLIER-DRIVEN.
  - All other metrics: |ρ| < 0.25, all non-significant.

  Scheme B (8cls):
  - davies_bouldin_index: ρ = -0.741 (p = 0.006). Significant, second only to silhouette.
    With KNN: ρ = -0.797. Modest drop of 0.06.
  - silhouette_score: ρ = +0.678 (p = 0.015). Significant predictor.
  - nc2_deviation_etf: ρ = -0.524 (p = 0.080). Borderline, NOT significant.
    With KNN: ρ = -0.909 (p < 0.0001) — a DROP of 0.39 in ρ.

WHY THE DROP FROM KNN TO LINEAR PROBE:
KNN F1 measures local proximity structure: how well-separated are same-class
neighbors? This directly correlates with cluster quality metrics (silhouette,
NC2, DBI). Linear probe F1 measures global linear separability: can a single
hyperplane per class discriminate the data? This is less directly tied to
pure cluster geometry — a dataset can have well-separated clusters but poor
linear boundaries (e.g., nested or non-convex clusters), and vice versa.

PRACTICAL VERDICT:
- Silhouette score remains a robust predictor of linear probe F1 across both
  schemes. It is the ONLY geometry metric we can confidently recommend.
- NC2 deviation is a strong predictor of KNN F1 but a WEAK predictor of
  linear probe F1. If the benchmark uses linear probe (as it canonically does),
  NC2 is NOT reliable for model ranking or selection.
- The KNN → LP drop highlights a methodological danger: geometric metrics
  validated against a non-parametric classifier (KNN) should not be assumed
  to transfer to a parametric linear classifier.

7. NOTE ON DAVIES-BOULDIN INDEX BEING LOO-FLAGGED
--------------------------------------------------------------------------------

DBI is flagged OUTLIER-DRIVEN in some configurations because it is sensitive
to the single poorest cluster pair. With only 11 or 8 classes, one model with
an anomalous cluster pair can dominate DBI. This is a known property of DBI,
not a bug. For low-n studies, silhouette (which averages over all points) is
more robust. DBI should be reported with LOO caveats.
